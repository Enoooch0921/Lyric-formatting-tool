# Lyric-formatting-tool
在製作 EasySlides 的歌詞中，適用於製作單行字幕、刪除標點符號、自動空行，以及刪除歌詞結尾的空白。

在第一個文字框中貼入歌詞並點選「一鍵格式化」，結果會出現在第二個文字框。

## 功能

- 自訂行寬並自動排版。
- 拖入 PPT／PPTX 後自動辨識多首歌曲、合併重複歌詞投影片，並選擇要匯入的歌曲。
- 拖入 Word DOCX，依歌名、空白分節與標題格式辨識歌曲；可選歌、匯入全部或保留整份原文。
- 辨識 `V1`～`V8`、`Verse 1`～`Verse 8`、`[1]`～`[8]`、`Chorus`、`Bridge`、`Pre Chorus` 等段落標籤。
- 將常見錯字 `Pro Chorus` 修正為 `[prechorus]`。
- 保守地移除明確的中文或英文翻譯行；中英混合與無法判定的內容會保留。
- 可移除每個段落或文字區塊中的雙數內容行，並可復原最近的操作。

線上使用：<https://enoooch0921.github.io/Lyric-formatting-tool/>

### PPT／PPTX 匯入

可拖入最多 50 MB 的 `.ppt`（PowerPoint 97–2003 二進位格式）或 `.pptx` 檔案。工具只讀取目前投影片清單的文字，不讀取母片範例、備註、文件屬性或歷史編輯文字，並排除頁首頁尾、日期與頁碼欄位；底部獨立的 `9-1` 類頁次也會排除。

透過頁碼重置、一至兩行歌名頁與背景變化（PPTX）辨識歌曲。每首歌可各自設定段落規則，先檢查完整段落預覽，再按匯入；設定與參考歌詞不會直接改動原始歌詞。

- **明確標記優先**：已有 `Verse 1`、`主歌一`、`Chorus`、`副歌`、`前副歌`、`橋段` 等標記時，依標記合併分頁，固定頁數不覆蓋標記。
- **沒有標記**：可選自動或每 1～4 個歌詞頁合成一段。計數前只移除連續相同頁；完整重複段落會合併，共用一頁但後續不同的段落仍保留。末段不足頁數保留，主歌超過八段的內容併入 `[8]`。自動模式只有演唱順序有重複證據時推測副歌；沒有可靠界線時保留為一段，並提示選擇頁數規則，不把每張投影片直接當成一段。
- **連續匯出編號**：無論有沒有參考歌詞或明確標記，主歌皆依實際匯入順序從 `[1]` 連續編號，最多到 `[8]`；副歌等標記不受影響。原版有 `[1]`、`[2]`、`[3]`、`[5]` 四段時，輸出為 `[1]`～`[4]`，不產生空段或跳號。原始／參考編號僅保留於提示及段落 metadata。
- **參考歌詞比對（選填）**：沒有參考也能直接選每幾頁合成一段，不需先貼歌詞。有參考時可貼入單首歌的完整歌詞，保留 `1.`～`8.` 或 Verse／Chorus 標記，按「套用參考歌詞」。沒有 PPT 標記且每頁都有可靠對應時，依參考段落分組，提示未找到的段落與部分缺漏，但匯出編號仍連續。少量字詞差異會提示，歌詞仍使用 PPT 原文，不自動替換或補入。共同歌詞無法唯一對應、或有未匹配頁時，保留目前分段而不強行套用。PPT 已有標記時只比對、不覆蓋分段。清空參考框再套用可取消比對。

匯入後請核對分歌、閱讀順序與段落標籤；複雜群組或特殊版型可能需要手動調整。圖片歌詞、加密檔案與更早期格式不支援，可解除保護或另存為 PPTX 再試。參考歌詞也只在瀏覽器處理，不搜尋網路、不上傳。

### DOCX 匯入

相同上傳區也支援最多 50 MB 的 `.docx`。可讀取一般段落、手動換行與表格文字，保留英文縮寫中的撇號。工具會結合歌名位置、空白段落、Word 標題格式與字級辨識歌曲；不會僅因多個空白行就拆成不同歌曲。每首歌有歌名與前兩行預覽，選擇後填入原始歌詞，也可匯入全部（含歌名分隔）。分歌結果不符合原文時，可選「匯入整份原文」自行調整。匯入可復原。

DOCX 已有 `Verse`、`Chorus`、`Pre Chorus` 等標籤時會保留其意義；沒有標籤時依空白分節編為主歌 `[1]`～`[8]`。只合併完整相同、標籤相同的段落，不會因歌詞出現相同字詞就刪除，也不會把重複段落直接猜成副歌。超過八段的未標記內容會併入 `[8]`，保留歌詞。

DOCX 目前不做圖片 OCR，也不讀取文字方塊、頁首頁尾與註解。表格依列與儲存格順序讀取，雙欄或雙語文件請核對順序。圖片與文字方塊會提示可能有遺漏。舊版 `.doc`、密碼保護的文件，請先在 Word 解除保護並另存為 `.docx`。

PPT、PPTX 與 DOCX 都在瀏覽器本機解析，不會上傳檔案。解壓縮使用 [fflate](https://github.com/101arrowz/fflate) 0.8.2（MIT License），舊版 PPT 容器使用 [SheetJS CFB](https://github.com/SheetJS/js-cfb) 1.2.2（Apache-2.0，授權見 `vendor/cfb-LICENSE.txt`）。程式均隨網站提供，不依賴外部 CDN；DOCX XML 使用瀏覽器內建解析器。

## 測試

需要 Node.js 20 或更新版本：

```sh
npm ci
npm test
```

每次 push 與 pull request 都會透過 GitHub Actions 執行相同測試。開發依賴 `@xmldom/xmldom` 僅供 Node.js 測試使用，不載入網站。匯入測試以程式產生合成文件，使用者提供的歌詞文件不會提交到儲存庫。
