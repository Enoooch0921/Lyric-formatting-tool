# Lyric-formatting-tool
在製作 EasySlides 的歌詞中，適用於製作單行字幕、刪除標點符號、自動空行，以及刪除歌詞結尾的空白。

在第一個文字框中貼入歌詞並點選「一鍵格式化」，結果會出現在第二個文字框。

## 功能

- 自訂行寬並自動排版。
- 拖入 PPTX 後自動辨識多首歌曲、合併重複歌詞投影片，並選擇要匯入的歌曲。
- 拖入 Word DOCX，依歌名、空白分節與標題格式辨識歌曲；可選歌、匯入全部或保留整份原文。
- 辨識 `V1`～`V8`、`Verse 1`～`Verse 8`、`[1]`～`[8]`、`Chorus`、`Bridge`、`Pre Chorus` 等段落標籤。
- 將常見錯字 `Pro Chorus` 修正為 `[prechorus]`。
- 保守地移除明確的中文或英文翻譯行；中英混合與無法判定的內容會保留。
- 可移除每個段落或文字區塊中的雙數內容行，並可復原最近的操作。

線上使用：<https://enoooch0921.github.io/Lyric-formatting-tool/>

### PPTX 匯入

可拖入最多 50 MB 的 `.pptx` 檔案。工具會在瀏覽器本機讀取投影片文字，透過頁碼重置、單行歌名頁與背景變化辨識歌曲，再將完整重複或局部重複的歌詞整理成段落。第一個段落優先視為主歌；副歌只會從後續重複段落判斷，並依照演唱順序保守辨識副歌前段（Pre Chorus）與後段橋段（Bridge）。證據不足時會使用主歌編號，不會強制猜測段落名稱。檔案不會上傳到伺服器。

### DOCX 匯入

相同上傳區也支援最多 50 MB 的 `.docx`。可讀取一般段落、手動換行與表格文字，保留英文縮寫中的撇號。工具會結合歌名位置、空白段落、Word 標題格式與字級辨識歌曲；不會僅因多個空白行就拆成不同歌曲。每首歌有歌名與前兩行預覽，選擇後填入原始歌詞，也可匯入全部（含歌名分隔）。分歌結果不符合原文時，可選「匯入整份原文」自行調整。匯入可復原。

DOCX 已有 `Verse`、`Chorus`、`Pre Chorus` 等標籤時會保留其意義；沒有標籤時依空白分節編為主歌 `[1]`～`[8]`。只合併完整相同、標籤相同的段落，不會因歌詞出現相同字詞就刪除，也不會把重複段落直接猜成副歌。超過八段的未標記內容會併入 `[8]`，保留歌詞。

目前不做圖片 OCR，也不讀取文字方塊、頁首頁尾與註解。表格依列與儲存格順序讀取，雙欄或雙語文件請核對順序。圖片與文字方塊會提示可能有遺漏。舊版 `.doc`／`.ppt`、密碼保護的檔案，請先在 Word／PowerPoint 另存為 `.docx`／`.pptx`。

PPTX 與 DOCX 都在瀏覽器本機解析，不會上傳檔案。解壓縮使用 [fflate](https://github.com/101arrowz/fflate) 0.8.2（MIT License），程式已隨網站一併提供，不依賴外部 CDN；DOCX XML 使用瀏覽器內建解析器。

## 測試

需要 Node.js 20 或更新版本：

```sh
npm ci
npm test
```

每次 push 與 pull request 都會透過 GitHub Actions 執行相同測試。開發依賴 `@xmldom/xmldom` 僅供 Node.js 測試使用，不載入網站。DOCX 測試以程式產生合成文件，使用者提供的歌詞文件不會提交到儲存庫。
